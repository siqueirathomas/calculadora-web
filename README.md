# 🧮 Calculadora Web

Uma calculadora responsiva desenvolvida com **HTML, CSS e JavaScript**, criada como projeto prático de estudo e desenvolvimento web.

## 🚀 Funcionalidades

* Operações de adição, subtração, multiplicação e divisão
* Porcentagem
* Botão para apagar o último caractere
* Botão para limpar a calculadora
* Suporte ao teclado do computador
* Interface responsiva para dispositivos móveis
* Tratamento de divisão por zero

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
